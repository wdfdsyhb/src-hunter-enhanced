# Contributing

Thanks for considering a contribution!

- **Bug reports**: open an issue with steps to reproduce (tool version, OS, command line).
- **Fixes / features**: PR against `main`, keep the diff minimal, tests stay green if the project has them.
- **Data corrections** (e.g. pin data in esp32-pinmap, vendor signatures in fake200): cite the datasheet or source you are correcting from.
- **New vendor signatures / boards**: one PR per vendor or board, with a sample response or datasheet reference.
